# Praxisverwaltung

Windows-Desktopprogramm für Sitzungsdokumentation, Rechnungen und Einnahmenübersicht.

## Windows EXE
GitHub Actions baut bei jeder Änderung automatisch `Praxisverwaltung.exe`.
Unter **Actions → Windows EXE → letzter Lauf → Artifacts** kann die fertige EXE heruntergeladen werden.

Die Programmdaten werden lokal unter `Dokumente/Praxisverwaltung` gespeichert.

> Hinweis: Diese erste Desktop-Fassung speichert Therapienotizen noch nicht verschlüsselt. Für echte Patientendaten erst nach Ergänzung der Verschlüsselung verwenden.
